# Security Policy — Dibyt

## Supported Versions

As Dibyt is currently under active foundation development (pre-v0.1), security fixes are applied directly to the `main` branch.

| Version | Supported |
|---|---|
| `main` (0.1.0-dev) | Yes |
| Pre-v0.1 Academic Prototypes | No |

---

## Reporting a Vulnerability

We take the security of Dibyt seriously. If you discover a security vulnerability or potential threat:

1. **Do not open a public GitHub issue.**
2. Send an email to the project maintainer (`rajpatel7807@gmail.com`) detailing:
   - Nature of the vulnerability (e.g., path traversal, buffer overflow, auth bypass).
   - Steps to reproduce or proof-of-concept code.
   - Affected system components or versions.
3. You will receive an acknowledgement within 48 hours.
4. We will coordinate a responsible disclosure timeline and credit you appropriately upon publishing the fix.
