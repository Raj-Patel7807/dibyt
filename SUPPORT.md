# Support — Dibyt

## Getting Help

Thank you for exploring **Dibyt**. Because the project is currently in its active development phase, please use the following channels for assistance:

1. **Documentation:** Review the comprehensive specifications in the [`docs/`](docs/README.md) directory, which cover product architecture, protocols, and design.
2. **Issue Tracker:** For verified bugs, specification defects, or architecture feedback, open an issue using our [GitHub Issues](https://github.com/Raj-Patel7807/Dibyt/issues) templates.
3. **Discussions & Questions:** For general design inquiries or questions about self-hosting plans, open a thread under GitHub Discussions.

Please note that pre-release developer preview builds do not carry commercial SLAs.
